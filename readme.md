## 1.プロダクトの紹介

スポーツチームが練習試合をするためのマッチングアプリを作成しました。

- 個人で１つのスポーツチームを登録
- チームの活動時間（空き時間）を登録
- 他チームの検索
- 自チームと他チームの空き時間が一致している場合、マッチング可能
- マッチングボタンを押して、予定確定


## 2.工夫した点，こだわった点

- 直感的に使いやすいことを意識した。

## 3.動画の操作内容

- ユーザー登録
- チーム内容作成
- チーム内容編集
- 10月の空き予定作成
- 種目による他チーム検索
- 別アカウントでのログイン
- 別アカウントでの予定登録
- 先ほど登録されたチームを検索
- 同じ空き時間でマッチング処理
- マッチング完了確認
